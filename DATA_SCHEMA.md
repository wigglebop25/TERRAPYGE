# TERRAPYGE Data Schema

## Overview

Defines the inputs, intermediate formats and outputs of the TERRAPYGE pipeline.

- Projected CRS: **EPSG:32651** (UTM Zone 51N), metres.
- Working grid: **334 x 301** pixels (width x height) at ~29.6 m — the SRTM 30 m
  grid resampled to the slope-unit analysis extent.
- Slope units: **13,297** polygons.
- Authoritative graph: `data/processed/buhisan/buhisan_hetero_physics.pt`
  (13,297 nodes, 21 features, spatial + hydrological edges).

All paths are relative to the repository root and resolved through
`src/terrapyge/utils/paths.py`. Files under `data/`, `results/` and `models/` are
gitignored and regenerated by the scripts in `scripts/`; see
`docs/ARTIFACT_MANIFEST.md` for the regeneration commands.

## 2. Processed Rasters (EPSG:32651, 334 x 301)

All rasters in `data/processed/buhisan/` are reprojected, resampled and aligned
to the conditioned DEM grid. Band counts below are the counts actually present
in the artifacts, which is one band for every raster except the 6-band soil.

| File | Bands | Dtype | Nodata | Description |
|------|-------|-------|--------|-------------|
| `dem_utm.tif` | 1 | float64 | NaN | DEM reprojected to UTM |
| `dem_conditioned.tif` | 1 | float64 | -32768 | Whitebox: fill depressions + pits |
| `slope.tif` | 1 | float32 | -32768 | Slope, degrees (Whitebox) |
| `aspect.tif` | 1 | float32 | -32768 | Aspect, degrees 0-360 (Whitebox) |
| `curv_plan.tif` | 1 | float32 | -32768 | Plan curvature (Whitebox) |
| `curv_profile.tif` | 1 | float32 | -32768 | Profile curvature (Whitebox) |
| `twi.tif` | 1 | float32 | -32768 | Topographic Wetness Index |
| `spi.tif` | 1 | float32 | -32768 | Stream Power Index |
| `soil_utm.tif` | 1 | float32 | NaN | Legacy single-band soil raster (feeds `soil_mean`) |
| `soil_6band_utm.tif` | 6 | float32 | NaN | clay, sand, silt, pH, bulk density, SOC |
| `worldcover_utm.tif` | 1 | uint8 | 255 | ESA class code |
| `dynamicworld_utm.tif` | 1 | float32 | NaN | Band 1 only |
| `chirps_utm.tif` | 1 | float32 | NaN | Annual rainfall (mm) |
| `worldclim_utm.tif` | 1 | float32 | NaN | Band 1 only |
| `era5_utm.tif` | 1 | float32 | NaN | Band 1 only |
| `jrc_water_utm.tif` | 1 | float32 | NaN | Band 1 only |
| `su.tif` | 1 | uint16 | 65535 | Slope unit IDs (1-13297) |

Note: the multi-band source rasters (DynamicWorld, WorldClim, ERA5, JRC) are
reduced to a single band during reprojection, so `su_features.csv` carries one
aggregated value per dataset rather than one per band. Only the soil raster keeps
all six bands, and it is consumed by the physics step (section 4), not by
`su_features.csv`.

## 4. Physics Features (`physics_features.csv`)

13,297 rows. Soil bands are aggregated from `soil_6band_utm.tif`; the remaining
columns are derived by `src/terrapyge/features/physics.py` using the `physics:`
block of `config.yaml`.

| Column | Definition |
|--------|------------|
| `su_id` | Slope unit ID |
| `clay_mean`, `sand_mean`, `silt_mean`, `bulk_density_mean` | Zonal mean of the corresponding 6-band soil band |
| `gamma_kNm3` | Unit weight from bulk density, `bd/100 * g`, clipped to [14, 20] |
| `c_prime_kpa` | Effective cohesion, `2.0 + 0.1 * clay`, clipped to [2, 10] |
| `phi_prime_deg` | Effective friction angle, `28.0 + 0.1 * sand`, clipped to [25, 38] |
| `static_fs` | Infinite-slope Factor of Safety with pore-pressure ratio `ru`, clipped to [1, 1000] |
| `critical_acc_g` | `(FS - 1) * sin(slope)`, floored at 0.01 |
| `arias_intensity` | `pi * PGA^2 * D / (6g)`, triangle approximation (m/s) |
| `newmark_dn_cm` | Jibson (2007) Model 1: `log10(Dn) = 0.561 log10(Ia) - 1.120 log10(Ac) - 0.552` |
| `physics_class` | 4-class label from `label_thresholds_cm` |
| `physics_label_binary` | 1 where `newmark_dn_cm >= binary_threshold_cm` |

Parameters from `config.yaml`: `pga_g = 0.4`, `duration_s = 10.0`,
`soil_depth_m = 2.0`, `pore_pressure_ratio = 0.15`,
`label_thresholds_cm = [2.0, 5.0, 15.0]`, `binary_threshold_cm = 2.0`.

The geotechnical relations are pedotransfer-style approximations for weathered
tropical residual soils and must be recalibrated wherever field or laboratory
data exist.

## 5. Graph Structure (PyTorch Geometric `HeteroData`)

### `buhisan_hetero_physics.pt` (authoritative)

```python
HeteroData(
    su = {
        x: FloatTensor[13297, 21],       # standardized features
        y: LongTensor[13297],            # binary physics label (0/1)
        num_nodes: 13297,
        feat_names: List[str],           # 21 names, order below
        scaler_mean: List[float],        # StandardScaler mean (21)
        scaler_scale: List[float],       # StandardScaler scale (21)
        crs: "EPSG:32651",
    },
    ('su', 'spatial', 'su') = { edge_index: LongTensor[2, 88772] },   # undirected
    ('su', 'hydro', 'su') = { edge_index: LongTensor[2, 24666] },     # directed D8
)
```

Edge type names are `('su', 'spatial', 'su')` and `('su', 'hydro', 'su')`.

### `buhisan_hetero.pt` (pre-physics intermediate)

Same nodes and edges, `x` is `FloatTensor[13297, 15]`, and there is **no** `y`
column. Produced by `scripts/build_spatial_edges.py` and consumed by
`scripts/build_physics_features.py`.

## 6. Labels

Labels are physics-derived, not observed. `y = 1` where Newmark displacement
reaches `binary_threshold_cm` (2.0 cm), which is the Moderate-or-higher class.

| Property | Value |
|----------|-------|
| Source | `newmark_dn_cm` (feature index 20) |
| Rule | `y = 1 if newmark_dn_cm >= 2.0` |
| Positive rate | 14.6% (1,935 / 13,297) |
| Classes | `physics_class` in `physics_features.csv` (0 Low, 1 Moderate, 2 High, 3 Very High) |

Because the label is a deterministic function of slope, and slope is itself an
input feature, full-feature AUC approaches 1.0 for every model. Only the
topographic-masked protocols in `results/spatial_cv.json` are informative about
graph value; see `ROADMAP.md` Known Issues.

## 7. Outputs

### Hazard map (`physics_hazard_map.*`)

| File | Format | Features | Properties |
|------|--------|----------|------------|
| `physics_hazard_map.gpkg` | GeoPackage | 13,297 | `su_id`, `value`, `label`, `landslide_prob`, `hazard_class`, `static_fs`, `newmark_dn_cm`, `geometry` |
| `physics_hazard_map.geojson` | GeoJSON | 13,297 | same as GPKG |
| `physics_hazard_map.csv` | CSV | 13,297 | attributes only |
| `physics_hazard_map.html` | HTML | — | interactive Folium map |

Class breaks use `hazard.method: quantile` with 4 classes
(`hazard.physics_n_classes: 4`), matching the physics class proportions:

| Class | Count |
|-------|-------|
| Low | 11,362 |
| Moderate | 1,652 |
| High | 239 |
| Very High | 44 |

`results/maps/` also holds legacy SAGE hazard outputs
(`hazard_sage_dual_edge.*`, `hazard_sage_hydro_only.*`) from the pre-physics
pipeline; they are not part of the current runbook.

### Model artifacts

| File | Format | Contents |
|------|--------|----------|
| `models/ablation/<variant>__<backbone>__<edges>.pt` | PyTorch `state_dict` | GNN checkpoints (see `models/README.md`) |
| `models/ablation/*.pkl` | Pickle | Non-graph baseline models |

The model used by the hazard-map step is set by `inference.model` and
`inference.edge_config` in `config.yaml`.

## 8. Results Directory

`results/` is gitignored; JSON metrics are regenerated by the scripts named
below.

| File | Produced by | Contents |
|------|-------------|----------|
| `physics_ablation.json` | `scripts/physics_ablation.py` | With vs without physics features (GNN + baselines) |
| `spatial_masking.json` | `scripts/spatial_masking_test.py` | Graph vs non-graph AUC under topographic masking |
| `spatial_cv.json` | `scripts/spatial_cv.py` | Random vs spatially blocked folds, transductive vs inductive |
| `bootstrap_ci.json` | `scripts/bootstrap_ci.py` | Bootstrap 95% CIs for AUC/AP/F1 |
| `significance.json` | `scripts/significance_tests.py` | Paired significance tests between models |
| `figures/*.png` | the scripts above | Regenerated plots; curated copies tracked in `docs/figures/` |

`results/ablation_study.json`, `results/baseline_comparison.json` and
`results/model_comparison.json` are legacy outputs from the pre-physics pipeline
archived under `scripts/legacy/`.

## 10. Data Quality Checks

| Check | Expected | How |
|-------|----------|-----|
| DEM non-negative after mask | `min >= 0` | `np.nanmin(dem) >= 0` |
| SU raster unique count | 13,297 | `len(np.unique(su_raster))` |
| SU vector feature count | 13,297 | `len(gdf)` |
| Graph node count | 13,297 | `data['su'].num_nodes` |
| Graph feature count | 21 | `data['su'].x.shape[1]` |
| Spatial edge symmetry | undirected | `(edge_index == edge_index.flip(0)).all()` |
| Feature NaN ratio | < 5% | `np.isnan(X).mean() < 0.05` |
| Label balance | 14.6% positive | `y.float().mean()` |
