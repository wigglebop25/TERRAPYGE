# TERRAPYGE

**Physics-Informed Graph Neural Network for Earthquake-Induced Landslide Susceptibility Mapping Using Slope Units with Spatial and Hydrological Edge Modalities**

A physics-informed Graph Neural Network framework for earthquake-induced landslide susceptibility mapping that uses Slope Units with spatial and hydrological edge modalities, applied to the Buhisan Watershed, Cebu City, Philippines.
